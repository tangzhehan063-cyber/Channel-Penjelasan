# Templat storyboard (dirancang sebelum kode; boleh disesuaikan)

Tidak ada jumlah shot/panel/layout wajib. Komposisi sama untuk beberapa shot boleh bila perubahan objek progresif lebih efektif; komposisi baru bila bermakna. Sketsa = SVG kasar atau uraian; bukan tangkapan render.

Kepala: video, kategori, arah visual (palet, tingkat detail, perspektif utama), teknik utama.

| Shot | Waktu/durasi | Narasi | Tujuan bercerita | Konsep visual | Komposisi (subjek + posisi, latar, hierarki) | Sudut/kamera (bila perlu) | Gerak objek dan **urutan animasi** | Transisi | Pendekatan teknis |
|---|---|---|---|---|---|---|---|---|---|
| 1 | | | | | | | staging · timing · anticipation · urutan · interaksi · sebab-akibat | | SVG/CSS · 2.5D · 3D terstilisasi · foto |

Catatan wajib bila ada mekanisme: **hubungan sebenarnya** (1–3 kalimat; sumber atau `[CEK]`) dan apa yang disederhanakan tanpa mengubah makna.
Periksa sebelum review: visual memperjelas/menguatkan/menambah (bukan mengulang narasi harfiah)? ada shot yang hanya angle berbeda dari sebelumnya? teknik terpilih paling jelas dan sesuai gaya? breakdown benar-benar dibutuhkan?
